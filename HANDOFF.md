# HANDOFF — Визуальная новелла «Мира»

## 🎯 Цель проекта и ОС
- **Цель**: Полнофункциональная реализация интерактивной визуальной новеллы «Мира» с эмоциональным ИИ-персонажем (модель Экмана: 6 базовых эмоций + neutral) по методическим указаниям (Продвинутый уровень, Вариант А: FastAPI + Web UI) на 100 из 100 баллов.
- **ОС**: Разработано на Windows, полностью кроссплатформенно (Windows / macOS / Linux).

## 🍎 Инструкция для демонстрации с macOS (Mac)
1. **Быстрый показ без терминала**:
   - Открыть в Safari / Chrome: `https://gr1nis.github.io/mira-ai-novel/`
   - Работает сразу "из коробки" в автономном демо-режиме (все 7 эмоций и диалоги по методичке).
2. **Показ с живой облачной моделью**:
   - В окне «Настройки» вставить ключ OpenRouter / Groq (`https://api.groq.com/openai/v1`, модель `llama-3.3-70b-versatile`).
3. **Локальный запуск на Mac**:
   ```bash
   git clone https://github.com/Gr1nis/mira-ai-novel.git
   cd mira-ai-novel
   pip install -r requirements.txt
   python run.py
   ```
   Открыть `http://localhost:8000`.

## 🏗 Ключевые архитектурные решения
1. **Автономный парсер с гарантированным fallback**: Любой сбой формата от модели (мусорный текст, обрезанный вывод, галлюцинированная эмоция) не ломает приложение, а откатывает эмоцию в `neutral`, сохраняя очищенный текст реплики.
2. **Скользящее окно 10 реплик**: Защита от переполнения контекстного окна LLM и деградации характера персонажа.
3. **Встроенный демо-режим**: В интерфейсе предусмотрена опция тестирования всех 7 эмоций и диалога даже при отключенной локальной Ollama.

## 🐛 Известные особенности
- Прямой winget-запрос к GitHub релизу Ollama на данной машине вызвал таймаут сети (типично для сетевых ограничений провайдера). Рекомендуется установить Ollama стандартным скачиванием или запускать через облачные модели (OpenRouter, Groq). В коде предусмотрен автономный демо-режим.
