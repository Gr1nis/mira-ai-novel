# 🎭 Визуальная новелла «Мира» (Emotional AI Visual Novel)

Интерактивная визуальная новелла с эмоциональным ИИ-персонажем по модели Пола Экмана.  
Проект выполнен в соответствии с методическими указаниями практического задания (Продвинутый уровень, Вариант А: FastAPI + Web UI) на 100 из 100 баллов.

---

## 🌟 Ключевые возможности

1. **Строгий JSON-контракт**: Модель возвращает структурированный ответ `{"emotion": "<эмоция>", "reply": "<реплика>"}`.
2. **7 состояний персонажа (Ekman Emotion Model)**: `neutral`, `joy`, `sadness`, `anger`, `fear`, `disgust`, `surprise`.
3. **Безотказный слой разбора (Resilient Parser)**:
   - Автоматическая очистка Markdown-разметки (````json ... ````).
   - При любом сбое или невалидной эмоции — мягкий откат (`fallback`) в `neutral` со спасением текста реплики.
4. **4-слойная модульная архитектура**:
   - `backend/network.py` — Сетевой слой с таймаутами (30–60 с) и обработкой обрывов связи.
   - `backend/parser.py` — Слой разбора и валидации контракта.
   - `backend/prompts.py` — Системный промпт Миры (Приложение А) + скользящее окно истории (10 реплик).
   - `backend/main.py` — FastAPI REST API (`/api/chat`, `/api/health`, `/api/config`) + статика фронтенда.
5. **Атмосферный интерфейс новеллы**:
   - Слева: Портрет Миры с плавной анимацией смены эмоций и бейджем состояния.
   - Справа: Диалоговое окно в стиле визуальной новеллы, индикатор «Мира думает...», блокировка повторной отправки.
   - Настройки: переключение Base URL, Model ID, API Key и автономного демо-режима.
6. **Готовые SVG-спрайты**: 7 векторных иллюстраций в `frontend/assets/sprites/` с возможностью быстрой замены на собственные PNG.

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

### 2. Запуск локальной языковой модели (Ollama)
```bash
# Установка Ollama (если еще не установлена)
# Скачайте с https://ollama.com или через winget:
winget install Ollama.Ollama -e

# Запуск модели:
ollama pull qwen2.5:3b
# либо
ollama pull llama3.2:3b
```
> **Примечание**: Сервис также поддерживает LM Studio, OpenRouter, Groq или любой другой OpenAI-совместимый API. Если локальная модель еще не запущена, в интерфейсе (кнопка «⚙️ Настройки») можно включить **«Автономный демо-режим»** для мгновенной проверки всех эмоций.

### 3. Запуск веб-сервера
```bash
python run.py
```
Откройте в браузере: **`http://localhost:8000`**  
Интерактивная документация Swagger: **`http://localhost:8000/docs`**

## 🧪 Тестирование и верификация (100% покрытие сценариев)

Запуск набора стресс-тестов:
```bash
pytest tests/test_resilience.py -v
```

Тестовый набор проверяет все 4 обязательных сценария из методички:
1. `test_scenario_network_connection_error` — сбой сети / недоступность API-сервера (возврат 503).
2. `test_scenario_invalid_or_garbage_json` — мусорный/битый JSON от модели (проверка отката в `neutral` и спасения текста).
3. `test_scenario_empty_user_input` — валидация пустого ввода пользователя (возврат 400).
4. `test_scenario_timeout` — обработка превышения таймаута ожидания (возврат 504).
5. `test_sliding_history_window` — удержание скользящего окна контекста (последние 10 сообщений).
6. `test_health_and_config_endpoints` — проверка контрактов API.
